# User Stories

## Solo User

```
As a freelancer,
I want to create a vault for my business income and expenses,
So that I can see my net balance at a glance without using a spreadsheet.
```

```
As a freelancer,
I want to add inflow and outflow transactions with descriptions,
So that I can remember what each payment was for.
```

```
As a freelancer,
I want the balance to update automatically,
So that I never have to do manual math.
```

```
As a freelancer,
I want to edit or delete a transaction if I made a mistake,
So that my records stay accurate.
```

## Partner Workspace

```
As a partner in a shared workspace,
I want to invite my partner to our vault,
So that we both see the same transactions.
```

```
As a partner in a shared workspace,
I want my partner's changes to appear on my device automatically,
So that we are always looking at the same numbers.
```

```
As a partner in a shared workspace,
I want to see if my partner made a change even if I was offline,
So that I know the data was updated.
```

```
As a partner in a shared workspace,
I want to know if my data has synced successfully,
So that I can trust the balance I'm seeing.
```

## Cross-Cutting

```
As any user,
I want to access my vaults even without internet,
So that I can always view and add transactions.
```

```
As any user,
I want my data to be secure,
So that no one else can read my transactions.
```
